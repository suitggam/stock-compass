1. 인프라 및 환경 설정 (Infrastructure & Setup)
[ ] Hadoop(HDFS) 환경 확인: Hadoop 클러스터가 정상적으로 실행 중인지, HDFS에 접근 가능한지 확인합니다.

[ ] HDFS 디렉토리 생성: 업로드될 엑셀 파일을 저장할 HDFS 내 특정 디렉토리를 생성합니다. (예: /user/data/excel_uploads)

[ ] Spark 클러스터 확인: Spark 클러스터가 Hadoop(YARN)과 연동되도록 설정되었는지 확인합니다.

[ ] Spark-Excel 의존성 추가: Spark에서 엑셀 파일을 직접 읽기 위해 spark-excel 라이브러리 의존성을 build.sbt, pom.xml 또는 Spark 실행 명령어(--packages)에 추가합니다.

2. 데이터 처리 파이프라인 (Data Pipeline)
[ ] 파일 업로드 프로세스 정의: 로컬 파일을 HDFS의 지정된 디렉토리로 업로드하는 방법을 결정합니다.

[ ] Spark 애플리케이션 개발: 키워드 추출 로직을 담은 Spark 애플리케이션을 개발합니다.

[ ] SparkSession 생성: 애플리케이션의 시작점인 SparkSession 객체를 생성합니다.

[ ] 데이터 로드: HDFS에 저장된 엑셀 파일을 Spark DataFrame으로 읽어옵니다. 헤더와 데이터 타입을 자동으로 인식하도록 옵션을 설정합니다.

[ ] 데이터 필터링: 요청받은 특정 기업들의 데이터만 추출하기 위해 filter() 또는 where()를 사용하여 DataFrame을 필터링합니다.

[ ] 키워드 추출 로직 구현:

    전처리: 분석할 텍스트 컬럼(예: '내용')에서 불필요한 특수문자, 공백, HTML 태그 등을 제거합니다.

    형태소 분석: 한국어의 경우, 정확한 키워드 추출을 위해 KoNLPy와 같은 라이브러리를 사용하여 명사, 동사 등 의미 있는 형태소를 추출합니다.

    불용어 제거: 의미 없는 단어(조사, 접미사 등)를 제거하여 핵심 키워드만 남깁니다.

    키워드 집계: 기업별로 추출된 키워드의 빈도를 계산하거나, 중요도(예: TF-IDF)를 측정합니다.

[ ] 결과 포맷팅: 추출된 키워드를 전송하기 쉬운 형태(예: JSON, CSV, Parquet)로 가공합니다.

JSON Example: { "기업명": "A회사", "keywords": ["기술", "혁신", "데이터"] }

3. 실행 및 전송 (Execution & Delivery)
[ ] Spark 작업 실행: 작성된 애플리케이션을 spark-submit 명령어를 통해 실행합니다.

[ ] 결과 전송 방법 결정: 처리된 결과를 어떻게 전달할지 정의합니다.

API 서버: 외부에서 API를 호출하면 Spark 작업을 실행하고, 결과를 JSON 형태로 응답합니다.

메시지 큐 (Kafka 등): 추출된 키워드를 메시지 큐에 전송하여 다른 시스템이 구독(subscribe)하여 사용하도록 합니다.

데이터베이스 저장: 결과를 RDBMS나 NoSQL 데이터베이스에 저장하여 필요시 조회하도록 합니다.

파일 시스템 저장: 결과를 다시 HDFS나 다른 파일 시스템에 저장합니다.

4. 자동화 및 운영 (Automation & Operation)
[ ] 워크플로우 자동화: 전체 과정을 자동화하기 위해 Apache Airflow나 Oozie 같은 워크플로우 관리 도구 도입을 검토합니다. (예: 파일 업로드를 감지하여 자동으로 Spark 작업 실행)

[ ] 로깅 및 모니터링: Spark 작업의 실행 상태, 성공/실패 여부, 성능 등을 추적하기 위한 로깅 및 모니터링 시스템을 구축합니다.

[ ] 예외 처리: 파일이 없거나, 포맷이 잘못되었거나, 특정 기업 데이터가 없는 경우 등 다양한 예외 상황에 대한 처리 로직을 애플리케이션에 추가합니다.
